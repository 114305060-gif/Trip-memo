# Trip Memo｜旅途手帳

一個以「溫暖咖啡館 × 紙本手帳」為設計風格的個人旅行紀錄網站，記錄台灣國內與世界各地的旅行足跡。

## 專案特色
- **規則驅動開發**：透過 `AGENTS.md` 明確定義色彩系統、檔案命名規則與 HTML 模板，讓 AI 能隨時依照統一規範擴充新的旅行日誌。
- **分類篩選功能**：支援「全部」、「台灣國內」、「國外旅遊」即時切換瀏覽。
- **純靜態網頁架構**：使用原生 HTML / CSS / JavaScript 製作，可零成本部署於 GitHub Pages。

## 目錄結構
- `AGENTS.md`：專案規範與 AI 擴充指南
- `index.html`：旅行手帳首頁
- `css/style.css`：手帳風視覺樣式表
- `templates/trip-template.html`：新增文章用標準模板
- `trips/`：各趟旅行的獨立日誌頁面（綠島、台南、蒙古、新加坡）
